Welcome to Downpour
====================

1. Drag Downpour.app to the Applications folder.
2. Before your first download, open Terminal and run:

   brew install yt-dlp ffmpeg

3. Open Downpour from Applications.

Downpour is built for Apple Silicon Macs running macOS 13 or newer.

This app is locally signed but not Apple-notarized. If macOS blocks its first
launch, open System Settings > Privacy & Security and choose Open Anyway.

Only download media you own or have permission to use.
